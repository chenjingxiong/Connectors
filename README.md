# StockSharp Connectors

本仓库包含 StockSharp (S#) 的所有开放连接器。

它们开放修改并欢迎新增 — 请随意更改现有连接器或贡献您自己的连接器。

> **注意：** Common 目录不计入子项目（无 .csproj）。
